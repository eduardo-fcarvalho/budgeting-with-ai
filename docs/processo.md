# Entrega de um card

Leia o objetivo e os critérios de aceite da issue no GitHub. Faça a mudança em branch
e descreva no PR os testes executados, as dependências novas e o risco do merge.
Os revisores de card e regras conferem o diff antes do envio. Use a lista de conclusão
do template do PR. Eduardo decide o merge. A publicação é uma decisão separada.
